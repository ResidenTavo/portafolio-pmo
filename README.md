# Gustavo Copara · PMO Estratégico

Página de portafolio profesional con la demo de **Orbit**, el tracker de portafolio de proyectos que diseñé: priorización, Business Case, monitoreo plan vs. real, costeo de horas y documentación en una sola fuente de verdad.

- Sitio estático: un solo `index.html`, sin dependencias ni base de datos.
- Los datos de la demo están en el bloque `DATOS` al inicio del `<script>`; edítalos ahí.
- Todos los proyectos, personas, fechas y montos son ficticios.

## Publicar en Vercel
1. En vercel.com → **Add New → Project** → importa este repositorio.
2. Framework Preset: **Other** → **Deploy**.
3. Cada cambio en `main` se publica solo.
